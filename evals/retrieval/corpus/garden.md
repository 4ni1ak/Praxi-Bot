# Balcony garden journal

## Early spring

The balcony receives morning sunlight and shade in the afternoon. Tomatoes use
the deepest containers, while parsley and mint grow in smaller pots near the
kitchen door. Each container has drainage holes and a saucer that can be emptied
after watering. Record observations about leaf color and soil moisture before
changing the watering schedule. A calendar reminder is only a prompt to inspect
the plants, not proof that every pot needs the same amount of water.

## Weekly notes

| Plant | Observation | Next check |
| --- | --- | --- |
| Tomato | New flower cluster | Inspect stem support |
| Mint | Healthy new leaves | Check pot boundary |
| Parsley | Uneven germination | Keep light consistent |

Use separate labels for the two tomato varieties. The seed packet contains the
variety name and approximate planting date, and the notebook records what
actually happened on this balcony. Photographs taken from the same position help
compare growth over several weeks. Avoid changing soil, fertilizer and position
on the same day, because then the next observation cannot distinguish which
change mattered.

## End of season

Clean reusable pots and store them dry. Keep the journal as ordinary notes so
next year's planting plan can refer to the actual conditions. This document is a
retrieval distractor with everyday vocabulary; it does not describe deployment,
database migrations, embedding providers or permission-system behavior.
