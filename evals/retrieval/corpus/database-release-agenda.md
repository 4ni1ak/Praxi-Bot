# Database release planning agenda

The weekly meeting includes a review of database migration proposals, deployment
status and backup ownership. The meeting secretary lists unfinished questions
about transaction retry, restore rehearsals, release manifests and cache
invalidation. No technical procedure was approved in this agenda.

Attendees should bring the MySQL transaction notes for a deadlock discussion and
the release operations runbook for the symlink publication discussion. Follow-up
decisions belong in those documents after review. Calendar attendance does not
authorize a production change.
