# Operations terminology

## Backup, restore and rollback

A backup is a saved copy. Restore means recovering data from that copy. Rollback
means returning an application to an earlier release. A release manifest is a
record associated with an artifact. These words appear together in incident
reports, but this glossary does not specify the checks or publication procedure
for any application. The backup rehearsal and release operations runbooks own
those procedures.

## Retry vocabulary

Retry, checkpoint, transaction and idempotency describe different parts of a
workflow. A cache namespace is an identifier. An embedding profile describes a
vector configuration. This glossary provides definitions for onboarding; it
does not say which database operation to retry or how to recover a failed job.
